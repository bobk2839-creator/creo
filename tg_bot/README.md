# OmniVoice Telegram Bot

Telegram-бот для генерации речи с использованием модели OmniVoice с возможностью монетизации.

## Возможности

- **Генерация речи** из текста с поддержкой 600+ языков
- **Клонирование голоса** по аудио-референсу
- **Дизайн голоса** с настройкой параметров (пол, возраст, тембр, акцент)
- **Система подписок** и оплаты за использование
- **Админ-панель** для управления пользователями и тарифами

## Структура проекта

```
tg_bot/
├── bot/              # Обработчики Telegram бота
├── models/           # Модели данных
├── services/         # Бизнес-логика (генерация аудио, оплата)
├── database/         # Работа с БД
├── payments/         # Платежные системы
├── config/           # Конфигурация
├── utils/            # Утилиты
└── main.py           # Точка входа
```

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения (см. `.env.example`)

4. Запустите бота:
```bash
python main.py
```

## Монетизация

Бот поддерживает следующие модели монетизации:

1. **Подписки**: Ежемесячная оплата за неограниченное использование
2. **Pay-per-use**: Оплата за каждую сгенерированную минуту аудио
3. **Пакеты голосов**: Покупка премиум-голосов
4. **Донаты**: Добровольные пожертвования

## Переменные окружения

Создайте файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=sqlite:///bot.db
OMNIVOICE_MODEL=k2-fsa/OmniVoice
PAYMENT_PROVIDER_TOKEN=your_payment_token
ADMIN_IDS=123456789,987654321
```
